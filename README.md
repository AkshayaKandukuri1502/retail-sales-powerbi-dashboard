# Retail Sales & Business Performance Analytics Dashboard

## Overview

An interactive Power BI dashboard developed to analyze retail sales performance, profitability, regional trends, product performance, and customer segments.

## Tools Used

- Power BI
- DAX
- CSV
- Data Analysis
- Data Visualization

## Dataset

The dataset contains 100 sample retail transactions with information about:

- Order Date
- Region
- Category
- Product
- Sales
- Quantity
- Profit
- Customer Segment

## Dashboard Pages

### 1. Executive Overview

- Total Sales
- Total Profit
- Total Quantity Sold
- Profit Margin
- Monthly Sales Trend
- Sales by Region
- Sales by Customer Segment

### 2. Product & Regional Analysis

- Sales by Category
- Profit by Category
- Top 10 Products
- Region vs Category Performance

### 3. Customer Analysis

- Sales by Customer Segment
- Profit by Customer Segment
- Average Order Value
- Product Performance Table
- Interactive Filters
